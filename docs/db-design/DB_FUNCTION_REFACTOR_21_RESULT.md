## 무엇이 바뀌었는가

1. **입력·청크 목록의 중복 순회를 줄였다.** 필수 항목 확인과 복사를 합치고, 청크 ID의 타입 검사와 집합 생성을 합쳤다. 원본 사전·목록은 보존해 호출자 자료를 변경하지 않고 중복 청크도 계속 검출한다.
2. **이미 확정된 입력·조건을 다시 처리하지 않게 했다.** 공개 업로드/재시도에서 검사한 ID를 내부에서 재검사하지 않는다. 검증된 기존 문서 ID의 UUID 대체 분기, 동일 불리언 설정, 정규화된 성공 상태 재확인도 정리했다. 관리자·세션·회사 상태를 잠금 뒤에 확인하는 처리는 유지했다.
3. **동일 점검의 구조 읽기·변환 결과를 공유했다.** split 연결 CLI의 중복 메타데이터 읽기와 검증 함수의 중복 정규화를 줄였다. 다른 요청에 결과를 캐시하지 않으며, 다음 점검은 다시 읽는다. 원본 layout을 변경하지 않는 회귀도 확인했다.
4. **DB에서 필요한 범위만 조회한다.** 여러 문서의 회사 소유 조회를 한 SELECT로 모으고, 미복구 게시 작업은 제외 조건을 적용해 최대 1행만 조회한다. 없는/소유 회사가 모호한 문서의 기존 제외 규칙과 DB 오류 전달을 유지했다.
5. **모듈 함수 중심 구조와 설명을 유지했다.** 함수·메서드 총 125개를 유지했고 신규 DB 함수·클래스를 추가하지 않았다. 변경한 조건·반복에는 한국어 설명을 맞췄다. URL 및 표현식의 중복 파싱·변환도 정리했다.
