# P3 격리 MySQL 전체 테스트

기존 건너뜀 86개는 다른 5개 DB 테스트 주소가 설정되지 않아 발생했다. 테스트는 운영 DB를 보호하기 위해 로컬 전용 빈 DB가 없으면 실행하지 않는다. 분리 DB까지 포함해 여섯 개의 독립 테스트 DB가 필요하다.

1. 프로젝트 가상환경에 `requirements.txt`의 의존성과 MySQL 8을 준비한다. PDF 테스트를 포함하려면 `pypdfium2`도 필요하다.
2. PowerShell에서 `MYSQL_BASEDIR`을 MySQL 설치 폴더로 지정한다. 예: `$env:MYSQL_BASEDIR = 'C:\mysql-8.4'`.
3. 저장소 루트에서 `.\.venv\Scripts\python.exe -m hyundap.tests.run_isolated_mysql`을 실행한다. 이 실행기는 임시 데이터 폴더와 `127.0.0.1` 전용 MySQL을 새로 만들고, 테스트를 마치면 해당 서버와 폴더를 정리한다. 건너뜀도 실패 종료 코드로 보고한다.

테스트 계정은 이 임시 MySQL에만 생성되며 회사 DB·계정과 권한 생성 시험을 위해 해당 인스턴스의 관리 권한을 갖는다. 외부 DB나 기존 로컬 MySQL에 연결하거나 데이터를 삭제하지 않는다. 테스트의 수집·임베딩 대역은 실제 API·벡터 저장 검증과 구분해야 한다.

2026-10-28 검증: Windows의 새 격리 MySQL 8.4.13에서 위 실행기로 전체 테스트 549개 통과, 실패·오류·건너뜀 0개를 확인했다. 회사별 계정 모드 전환, 호스팅 환경변수 읽기 및 만료된 세션의 과거 시각 우회 거부를 포함한다.

앱의 기본 backend 모드는 실제 인증 서비스와 문서 처리 함수를 연결한다. 데모 모드는 별도로 선택한다. 회사별 계정은 `HYUNDAP_DB_LAYOUT=split`, `HYUNDAP_DB_COMPANY_ACCOUNTS=1`을 명시할 때 사용하며, 회사 등록은 관리 CLI를 통해 수행한다. 기존 회사의 계정은 자동으로 전환하지 않는다.

시험용 기본 설정은 Git 제외 로컬 파일에 평문으로 저장되며, 다중 프로세스 쓰기를 지원하지 않는다. 호스팅에서는 `HYUNDAP_COMPANY_CREDENTIALS_SOURCE=environment`와 `HYUNDAP_COMPANY_DATABASE_CREDENTIALS`에 회사 ID별 `username`, `password`를 담은 JSON을 서비스 비밀 변수로 주입할 수 있다. 값이 없거나 잘못되면 로컬 파일로 대체하지 않는다. Railway의 sealed 변수는 배포된 서비스에 제공되며 UI와 API에서는 값을 읽을 수 없다.

Railway 변수 변경은 별도 배포가 필요하다. 따라서 현재 환경변수 방식에서 회사 계정의 자동 생성은 DB 객체를 만들기 전에 차단된다. 호스팅 비밀의 자동 등록과 배포 완료 확인을 회사 활성화 절차에 연결하는 작업은 아직 남아 있다. 또한 프로시저·뷰 변조 검증, 계정 생성 실패 복구 및 실제 임베딩·검색 경로 검증이 필요하다. 회사 계정 방식은 실서비스 전환이 완료된 상태가 아니다.

## Railway 로컬 파일 방식 실연결 검증 (2026-10-28)

- `MySQL-RKHA`의 별도 공통 시험 DB `p3_local_control_c6e5fc8de908`에 회사 2곳과 회사별 DB·MySQL 계정 2개를 신규 생성하고 모두 `ready`를 확인했다. 기존 공통 DB의 실험 객체와 업무 데이터는 수정하지 않았다.
- 회사별 관리자 계정의 실제 로그인과 세션을 검증하고, 각 회사 계정으로 자기 DB에 연결했다. 공통 `users`와 다른 회사의 `documents` 직접 조회가 각각 거부됐다.
- 별도 프로세스에서 Git 제외 로컬 파일을 다시 읽어 두 회사 DB에 연결했다. 로컬 앱 backend 모드가 7876 포트에서 HTTP 200을 반환하고, 별도 플랫폼 관리자 시험 계정의 로그인·로그아웃이 성공했다.
- 공통 DB는 관리자 계정을, 회사 DB는 각 회사의 제한 계정을 사용했다. 시험 회사·사용자·DB 및 로컬 비밀 파일은 보존했다. 문서 업로드·임베딩·브라우저 로그인은 이번 실연결 시험에 포함되지 않는다.
