# 현답 작업 폴더 구조

작업 폴더는 기획안 ver2의 역할 분담에 맞춰 기능 폴더 7개와 테스트 폴더 1개로 나눕니다. 한 폴더는 한 사람이 책임지고, 다른 폴더의 기능은 함수 호출로만 씁니다.

폴더마다 담당자를 적었습니다. 파일 이름은 예시이며, 담당자가 자신의 폴더 안에서 자유롭게 바꿀 수 있습니다.

```text
Hyundap/
├── app.py                  # Gradio 실행 진입점 · 박경환
├── requirements.txt        # 패키지 목록 · 이성민
├── .env.example            # 환경변수 예시 (실제 .env는 git 제외)
│
├── common/                 # 공용 설정·공통 문서 형식 · 이성민(관리)
│   ├── config.py           #   .env 읽기, 경로·모델 이름 설정
│   └── schemas.py          #   공통 형식(문서 헤더 + 섹션), 청크 구조
│
├── ui/                     # 화면 · 박경환
│   ├── login_page.py       #   통합 로그인
│   ├── search_page.py      #   검색·필터·결과 목록(스플릿 뷰)·문서 상세
│   ├── chat_page.py        #   챗봇 질의응답·출처·요약 표시
│   ├── admin_page.py       #   업로드, 계정 권한 설정·로그 확인(P2)
│   └── components.py       #   공통 스타일·로딩·확인 팝업(P2)
│
├── ingest/                 # 문서 수집·파싱·청킹 · 김혜리
│   ├── validator.py        #   형식·100MiB·손상·암호화·중복 검증
│   ├── loaders/            #   pdf_loader.py, docx_loader.py, pptx_loader.py
│   ├── normalizer.py       #   문자 정규화
│   └── chunker.py          #   섹션 경계를 넘지 않는 청킹, 위치 정보 보존
│
├── embedding/              # 임베딩 · 박영준
│   ├── embedder.py         #   기업명·문서 유형 메타데이터 포함 임베딩 생성
│   └── vector_store.py     #   ChromaDB 저장
│
├── search/                 # 통합 검색 · 이준영
│   ├── search.py           #   search(검색어, 필터)
│   └── filters.py          #   기업·문서 유형·권한·공개 상태 조건
│
├── chatbot/                # AI 챗봇·요약 · 소용우
│   ├── ask.py              #   ask(질문, 필터) 근거 기반 답변
│   ├── prompts.py          #   프롬프트 (근거 밖 내용 생성 제한)
│   ├── citations.py        #   회사·파일·페이지·발췌 출처
│   └── summary.py          #   선택 문서 요약(P2)
│
├── db/                     # 저장·버전·작업 기록 · 전재경
│   ├── schema.sql          #   documents, document_versions, document_chunks 등
│   ├── connection.py       #   MySQL 접속
│   ├── documents_repo.py   #   원본 저장, 후보 버전 등록, 활성 버전 공개
│   └── jobs_repo.py        #   처리 결과·실패 원인 기록
│
├── auth/                   # 인증·기업별 권한 · 전재경
│   ├── login.py            #   login(아이디, 비밀번호)
│   ├── password.py         #   Argon2id 해시·검증(P2)
│   └── permissions.py      #   역할·회사 범위 검사, 답변·다운로드 직전 재검증
│
├── tests/                  # 테스트 · 이성민
│   ├── test_ingest.py      #   폴더마다 test_<폴더>.py 하나씩
│   ├── test_search.py
│   └── fixtures/           #   테스트용 샘플 문서
│
└── data/                   # 실행 중 생기는 파일 (git 제외)
    ├── uploads/            #   원본 문서
    └── chroma_db/          #   벡터 DB
```

## 폴더 규칙

- 자기 폴더 안의 파일만 고칩니다. 다른 폴더의 기능이 필요하면 그 폴더의 함수를 호출합니다.
- common/ 의 공통 문서 형식은 ingest/ · embedding/ · search/ · chatbot/ 이 함께 씁니다. 바꾸기 전에 팀에 알리고, 관리자(이성민)가 반영합니다.
- data/ 와 .env 는 git에 올리지 않습니다.
- Day 5(10/28)에 각 폴더를 develop에 merge하고 Day 6부터 tests/ 로 통합 테스트를 진행합니다.
